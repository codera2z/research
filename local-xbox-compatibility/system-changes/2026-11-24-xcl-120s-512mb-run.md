# XCL — 120-second retail-game run with 512 MB coherent-window override

**Date:** 24 November 2026  
**Build status:** User confirmed the local executable is updated to current upstream `main` (see [current local source/build status](2026-11-24-xcl-current-main-status.md)); the exact binary SHA was not embedded in `xcl --version`.  
**Host GPU:** NVIDIA GeForce RTX 3050 Ti Laptop GPU, 3962 MiB reported by XCL  
**Host memory:** 15.7 GB physical RAM; fixed 24,576 MB pagefile; commit limit previously verified as 39.7 GB.

## Test configuration

- `XCL_NETWORK=0`
- `XCL_RUN_SECONDS=120`
- `XCL_COHERENT_MB=512`
- `XCL_ACTIVITY=1`

This was a deliberate 512 MB diagnostic override, not the normal adaptive coherent-window selection. The saved `cache/uma_coherent.txt` was not edited or deleted.

## Outcome

- Normal XCL timed stop after 120.103 seconds; report `crash = null`, exit code `0`.
- 669 PresentX calls over the run (~5.58 presentations/s).
- User saw the Rockstar logo and narration/menu sequence; no gameplay was reached.
- The separate rolling FPS sample was 6.3 FPS over the last 300 frames at approximately 109.7 seconds. This differs from the whole-run 669 / 120.103 ≈ 5.58 FPS.

## Graphics and decoding

- 540 translated pipelines.
- DXIL cache: 1,082 hits, zero misses, zero compilations and zero failures.
- 40 mesh-pipeline translation refusals: the console mesh-shader container was seen in the AS slot.
- BCPack decoding succeeded for all sampled requests: BC1 6, BC5 100, BC7 20; 126 total, zero failures, 10,027,008 output bytes (~9.56 MiB). This supersedes the earlier report of 126 refused chunks.
- Audio: 23 XAPU/Opus packets decoded, zero errors.

## Memory and performance

- Coherent UMA window: 512 MB; `uma_used_kb=119552` (~116.75 MiB).
- Process-private commit peaked around 16,008 MB.
- DXGI local/non-local `CurrentUsage` peaked around 6,655 / 1,360 MB. These are DXGI usage counters, not direct physical-chip residency measurements.
- The latest data does not include DXGI `Budget`, Windows available physical RAM, CPU utilization, CPU/GPU clocks or CPU/GPU temperatures. Do not infer exact budget overrun or thermal headroom.

## Interpretation

The run survived its full XCL-managed timer without the previous command-list `E_OUTOFMEMORY` failure. BCPack decompression is now working on the updated local build. The 512 MB override remains a confounder for performance comparisons; this is not a normal adaptive-window benchmark. The 40 refused mesh pipelines remain a graphics limitation, and a menu/logo run does not demonstrate successful gameplay.
