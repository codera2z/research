# XCL — 120-second retail-game run with 512 MB coherent window

**Date:** 24 November 2026  
**Build:** upstream `beaa245ca04e212f064efc7cafcdce104bc5c0a2`  
**Host GPU:** NVIDIA GeForce RTX 3050 Ti Laptop GPU, 3962 MiB reported by XCL  
**Host memory:** 15.7 GB physical RAM; fixed 24,576 MB `C:\pagefile.sys`; Task Manager commit limit previously verified as 39.7 GB.

## Test configuration

Executed the local `xcl.exe` with:
- `XCL_NETWORK=0`
- `XCL_RUN_SECONDS=120`
- `XCL_COHERENT_MB=512`
- `XCL_ACTIVITY=1`

The saved adaptive cache `cache\uma_coherent.txt` was not changed or deleted. The `report.json` and `xcl.log` at the repository root are the new 120-second run; `report.prev.json` and `xcl.prev.log` are the prior run.

## Outcome

- `report.json`: `crash = null`, `exit_code = 0`.
- `xcl.log`: at 120.005 seconds, XCL logged `XCL_RUN_SECONDS: 120 s – ending the title (757 frames shown, 757 PresentX calls)`, then completed its own shutdown. This was a timed stop, not a crash.
- User observation: the display reached the Rockstar logo and then a narration screen; the user estimates around 9.5 FPS. The run ended before they could determine whether it progressed beyond that screen.
- XCL's separate performance log at about 97.7 seconds reported 600 frames presented and 7.8 FPS over the last 300. Total presentations / total timed duration is 757 / 120 = 6.31 per second, which includes startup/loading; these are different measurement windows.

## Graphics and shader results

- 8,742 unique shaders discovered (8,634 Xbox-native, 108 DXBC).
- 20,308,180 RDNA2 instructions decoded; zero undecoded dwords and zero Xbox shader errors.
- 235 translated pipelines.
- Zero fallback and zero failed-pipeline counters.
- DXIL cache: 434 hits, 38 misses, 15 coalesced hits, 23 compilations, zero compile failures/errors.
- 40 mesh pipeline translation refusals: XCL reports the console mesh-shader container in the AS slot and refuses those pipelines. This remains the same class of limitation documented in upstream `HANDOFF.md`; do not claim gameplay works.

## Coherent UMA window and memory observations

- `d3d12.uma_mb = 512`.
- `d3d12.uma_used_kb = 119552` (116.75 MiB). The coherent window was nowhere near full, unlike the previous 4,095 MB run that approached 3,998.6 MB.
- 59 activity snapshots were recorded, beginning at 2 seconds and continuing to 118.3 seconds.
- The `memory:` activity field uses `PROCESS_MEMORY_COUNTERS_EX.PrivateUsage`; it reports process-private commit, not the resident working set / physical RAM in use. It started at 5,798 MB, reached a maximum of about 16,074 MB at 112.3 seconds, and was stable around 16,029–16,074 MB through most of the final minute.
- DXGI local video-memory `CurrentUsage` peaked at about 6,654 MB; non-local peaked at about 1,359 MB. These are per-process DXGI usage counters for local/non-local memory segments, not direct physical-chip occupancy readings.
- XCL's activity output also showed target pages peaking around 3,597 MB (page pools 3,648 MB), arenas around 397 MB in use (461 MB made), sparse pools around 960 MB (953 MB mapped). These are XCL's categories and should not be added together as if they were separate physical allocations.
- The log does **not** include the DXGI `Budget` value. Microsoft documents that `CurrentUsage` over the OS-provided budget can cause stuttering/performance penalties. Without the budget, the over-budget amount is unknown.
- No CPU utilization, CPU temperature, GPU temperature, clocks, total system available physical RAM, or system-wide commit was captured in this run. Therefore thermal headroom and whole-machine physical-memory pressure cannot be certified from this log.

## Audio / services / remaining errors

- Report: 90 XAPU/Opus packets decoded, 84,528 frames, 76,455 non-zero samples, zero decode errors.
- DirectStorage BCPack refusals: BC1 = 6, BC5 = 100, BC7 = 20; total 126 refused requests. The log reports these requests failing with decompression errors.
- System `xgameruntime.dll` remains missing; XCL uses its fallback. `XDisplay` is missing, `XStore` unavailable while offline, and `XSpeechSynthesizerCreate` is unimplemented.
- The game still has XCL stubbed / unsupported D3D12.X methods; see the full report for call counts. Do not assume the current screen proves game compatibility beyond the observed boot path.

## Interpretation

The 512 MB coherent-window override clearly prevented the previous large coherent-window saturation: the new run remained at about 117 MB of 512 MB, lasted the full 120-second timer, reached the Rockstar logo and narration screen, and did not report a crash. This is a strong improvement over the two prior `E_OUTOFMEMORY` failures on the 4,095 MB window.

Low frame rate remains explainable by several factors. XCL reports that this GPU runs 32-lane waves, so console 64-lane programs are split into two halves (slower and with known correctness caveats). DXGI local usage around 6.65 GB is above the adapter's 3.96 GiB reported physical VRAM capacity, which is a warning sign for memory pressure, but not proof that the full amount is physically resident or that the OS budget was exceeded. The 16.1 GB process-private commit is also substantial compared with 15.7 GB installed RAM, though it is not an RSS/working-set measurement. Missing budget/thermal/working-set data prevents a definitive root-cause attribution.

## Suggested next step

A bounded 180-second run with the same `XCL_COHERENT_MB=512`, `XCL_ACTIVITY=1`, and `XCL_NETWORK=0` is reasonable only with concurrent monitoring. Capture:
- Windows available physical memory and system committed bytes / commit limit.
- XCL process-private commit and pagefile usage.
- CPU utilization.
- NVIDIA GPU temperature, utilization, dedicated memory usage, power and clock using `nvidia-smi` if available.
- CPU package temperature using an existing laptop/OEM sensor utility or HWiNFO if already installed.

Do not increase the coherent window, delete the DXIL/shader cache, change the pagefile, or remove the run timeout based on this test alone. Stop after 180 seconds and review the new log/report before extending further.
